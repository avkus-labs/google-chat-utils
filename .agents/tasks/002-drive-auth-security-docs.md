## 2. Часть A — Google Drive OAuth + получение чата по имени

Цель: команда (или флаг существующей команды `parse`/`distill`), которая по имени чата находит файл в папке Google AI Studio на Drive нужного аккаунта, скачивает его и кладёт в `input_data/` (или напрямую передаёт в существующий пайплайн парсинга), не требуя от пользователя ручного экспорта через интерфейс Drive.

- Библиотеки: `google-auth`, `google-auth-oauthlib`, `google-api-python-client` (добавить в `requirements.txt` и `pyproject.toml`, зафиксировать версии).
- Авторизация: OAuth2 user-flow. Креды клиента (`client_id`/`client_secret`) — из переменных окружения (`GDRIVE_CLIENT_ID`, `GDRIVE_CLIENT_SECRET`), НЕ хардкодить, НЕ коммитить. Refresh-токен — из переменной окружения (`GDRIVE_REFRESH_TOKEN`) или локального файла вне git (добавь путь в `.gitignore`, если такого файла ещё нет там). Если для первичного получения refresh-токена нужен интерактивный consent-flow — сделай отдельную одноразовую CLI-подкоманду (`auth-drive` или похожую), которая выводит инструкцию и не пытается заменить нормальный OAuth consent screen.
- Новая команда, например: `python utils/cli_v3.py fetch-drive --chat-name "<имя>" [--output_dir input_data/]`. Поиск: `files.list` с `q="name contains '<имя>' and '<ID_папки_или_имя_папки>' in parents and trashed = false"`. ID папки "Google AI Studio" — не хардкодь: сначала резолвь по имени папки через отдельный `files.list` с `mimeType = 'application/vnd.google-apps.folder'`, либо прими ID папки как опциональный флаг/переменную окружения (`GDRIVE_STUDIO_FOLDER_ID`) с фолбэком на резолв по имени.
- Скачивание: `files.get_media`, сохранить как есть (raw bytes → текст/JSON), не через экспорт Google Docs.
- Ошибки: несколько файлов с похожим именем → вывести список кандидатов (имя, id, дата изменения), не скачивать наугад первый; файл не найден → понятная ошибка, код выхода ≠ 0; ошибки авторизации (401/403/invalid_grant) → понятное сообщение с указанием, какую переменную окружения проверить, не стектрейс библиотеки как есть.
- Тесты: мокать `google-api-python-client` (`unittest.mock`), без реальных сетевых вызовов и без реальных кредов в тестах. Юнит-тесты на: резолв папки по имени, фильтрацию кандидатов при неоднозначном имени, обработку ошибки авторизации, happy path (скачивание → файл сохранён).
