# 006 — Целостность дистилляции: пустые ответы, строгая верификация, чаты без реплик пользователя

## 2. Требуемое поведение
**A. Пустой ответ = ошибка, не кэшируется.**
1. В `chat_completion` (стрим и не-стрим): `content.strip() == ""` при `finish_reason == "stop"` → `ChunkFailedError("empty response")` с теми же ретраями, что у сетевых ошибок (`MAX_RETRIES`), затем отказ. Не возвращать пустую строку.
2. В `pipeline.py`: `cache.put` не вызывается для пустого/пробельного содержимого; `cache.get` результата `""` трактовать как промах (чтобы уже отравлённые кэши не воспроизводились).
3. То же для synthesis: пустой ответ → `DistillError` с понятным сообщением.

**B. Статус верификации честный.**
1. Статусы: `ok` | `warning` | `error`. `warning`, если есть любое из: непокрытые ходы; якорь вне диапазона `1..turn_count`; якорь-заглушка (`N–N`, `[не указаны]`, `[не указан`); `code_blocks` выше порога (см. C). `error` — как сейчас (секреты).
2. Во frontmatter `verification:` писать компактно: `turn_coverage` (число и сжатые диапазоны пропущенных, например `1-131`), `anchor_issues` (число), `code_blocks` (число подозрительных из N), `status`. В консоль — те же сведения.
3. Флаг `--distill_strict` (в `_add_distill_options`, `DistillConfig.strict: bool=False`): при покрытии ходов < 100% или любых `anchor_issues` — `DistillError`, файл не записывать (кэш чанков остаётся).

**C. Проверка кода без ложных срабатываний.**
Нормализация (CRLF, хвостовые пробелы, серии пробелов/табов → один пробел, `…`→`...`, типографские кавычки и тире → ASCII) и построчная проверка: блок подозрителен, если не найдено в источнике более 30% его непустых строк (минимум 2 строки). Блоки, где все строки найдены, но целиком не склеиваются, подозрительными не считаются. Предупреждение содержит номера блоков.

**D. Чаты без реплик пользователя (ручная чистка).**
1. `prepare`: если после удаления мыслей/System Instruction нет ни одного `### **User**` заголовка, добавить в начало подготовленного текста НЕнумеруемую пометку `[примечание пайплайна: в диалоге нет реплик пользователя (удалены при ручной очистке); подтверждений со стороны пользователя нет]`. Виртуальных реплик пользователя НЕ добавлять; нумерация ходов и `turn_count` не меняются.
2. `plan_line` для таких файлов добавляет `⚠ нет реплик пользователя`.
3. Если после очистки суммарное содержимое ходов (без заголовков) короче 200 символов — файл пропускать с явным сообщением «нет содержимого для дистилляции» и кодом ошибки файла, а не писать пустой дистиллят.
4. Промпты `prompts/distiller_chunk_prompt.md` и `prompts/distiller_chunk_prompt_ru.md`: добавить в `<status_marks>` правило «если во фрагменте нет реплик пользователя или есть пометка пайплайна об их удалении, статус `[подтверждено]` не используется: всё, что исходит от модели, помечается `[предложено моделью]`». Формат якорей `(ходы A–B)` и остальные правила не менять.

**E. Документация.** `README.md`, `CLAUDE.md`, `CHANGELOG.md`, версия (patch-bump). Отдельно описать: что `source_sha256` считается по тексту после перевода CRLF → LF; статусы верификации; `--distill_strict`.

## 3. Тесты (только моки, без сети, `tmp_path`)
- Пустой ответ чанка (стрим и не-стрим) → `ChunkFailedError` после ретраев; пустое не попадает в кэш; в предзаполненном кэше значение `""` даёт промах и повторный вызов.
- Пустой ответ synthesis → `DistillError`.
- Верификатор: пропущенные ходы → `warning` + диапазоны в `verification` frontmatter; якорь `(ходы N–N)`, `(ходы [не указаны])`, якорь вне диапазона → `anchor_issues`; полное покрытие → `ok`; секрет → `error`.
- `--distill_strict`: покрытие < 100% → `DistillError`, `_distilled.md` не создан; при 100% — создан.
- Код: блок из строк, присутствующих в источнике, но склеенный иначе → не подозрительный; блок с 50% выдуманных строк → подозрительный; `…`/`...` и CRLF не ложнят.
- Файл только с `### **Model**` заголовками → пометка в подготовленном тексте, `turn_count` не меняется, `plan_line` с предупреждением; файл с заголовками и пустыми телами → пропуск с сообщением.
- Существующие тесты не ослаблять; `python -m pytest` целиком.
