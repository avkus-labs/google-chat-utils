# ROADMAP.md

Этот файл содержит план развития проекта Google Chat Utils.

## 📌 В планах (Backlog)

### 1. Архитектура и CLI
- [ ] **Расширение CLI:** Добавление интерактивного режима (`interactive mode`) для пошагового выполнения операций парсинга и реконструкции.
- [ ] **Валидация данных:** Внедрение Pydantic-схем для строгой валидации входящих JSON-экспортов из Google AI Studio на ранних этапах.
- [ ] **Улучшение логгирования:** Добавление более детальных логов исполнения команд для упрощения отладки в CLI.

### 2. Функциональность (Парсинг и Реконструкция)
- [ ] **Поддержка других AI-платформ:** Исследование возможности расширения парсера для работы с экспортами чатов из других сервисов (например, ChatGPT, Claude).
- [ ] **Интерактивные шаблоны:** Разработка системы более динамических шаблонов для реконструкции кода, позволяющих задавать параметры через CLI аргументы (в дополнение к файлам-оверрайдам).
- [ ] **Улучшение Markdown RAG:** Оптимизация формата Markdown, генерируемого для RAG (Retrieval-Augmented Generation), для лучшей индексации в LLM.

### 3. Инструменты (Transformation & Tools)
- [ ] **Расширение `SchemaTransformer`:** Добавление поддержки конвертации между схемами JSON Schema и более сложными типами данных (например, Pydantic-моделями).
- [ ] **GUI прототип:** Создание простого веб-интерфейса (на базе существующих HTML-документов в `docs/html`) для визуального управления парсингом и реконструкцией.

### 4. Тестирование и Качество
- [ ] **Увеличение покрытия тестами:** Покрытие тестами модуля `transformation` и новых функций CLI.
- [ ] **CI/CD:** Настройка автоматического прогона тестов при пуше в ветки `main` и `dev`.
