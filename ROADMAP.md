# Дорожная карта проекта (Roadmap)

Этот документ описывает стратегическое видение и планируемые улучшения для проекта `google-ai-studio-chat-parser`.

---

## Этап 1: Стабилизация и Профессионализация

*Цель: Превратить утилиту в надежную, легко распространяемую библиотеку.* 

- **1.1. Внедрение комплексного тестирования:**
  - **Задача:** Создать набор юнит-тестов для проверки всех ключевых компонентов: `parser`, `reconstructor`, `transformer`, `CLI`.
  - **Результат:** Гарантия того, что новые изменения не ломают существующий функционал.

- **1.2. Настройка CI/CD:**
  - **Задача:** Интегрировать GitHub Actions для автоматического запуска тестов при каждом коммите и pull-request.
  - **Результат:** Автоматизированный контроль качества кода.

- **1.3. Упаковка и публикация на PyPI:**
  - **Задача:** Подготовить проект к дистрибуции (создать `pyproject.toml`), чтобы его можно было устанавливать через `pip`.
  - **Результат:** `pip install google-chat-utils`.

---

## Этап 2: Расширение возможностей и Developer Experience (DX)

*Цель: Сделать инструмент более мощным и удобным для конечного пользователя.*

- **2.1. Поддержка других LLM-платформ:**
  - **Задача:** Создать и добавить официальные шаблоны для реконструкции кода под **Anthropic (Claude)** и **OpenAI (GPT)**.
  - **Результат:** Возможность генерировать код для разных API из одного и того же промежуточного JSON.

- **2.2. Интерактивный режим CLI (`--interactive`):
  - **Задача:** Добавить флаг `-i`, который запускает пошаговый мастер, задающий вопросы пользователю (путь к файлу, выбор шаблона и т.д.).
  - **Результат:** Снижение порога входа для новых пользователей.

- **2.3. Команда валидации (`validate`):
  - **Задача:** Создать новую подкоманду `validate` для проверки JSON-файлов на соответствие схеме и логическую корректность до начала основной работы.
  - **Результат:** Быстрое получение отчета об ошибках в данных.

---

## Этап 3: Экосистема и продвинутые рабочие процессы

*Цель: Выйти за рамки простого парсера и стать инструментом для управления жизненным циклом промптов.*

- **3.1. Двунаправленная синхронизация (`sync`):
  - **Задача:** Создать команду, которая может сравнивать локальную версию чата с версией в Google AI Studio и предлагать варианты слияния изменений.
  - **Результат:** Полноценная синхронизация между локальной и облачной средой разработки.

- **3.2. Управление проектами:**
  - **Задача:** Ввести поддержку конфигурационного файла (`studio_project.yaml`), описывающего несколько чатов и их взаимосвязи, для пакетной обработки.
  - **Результат:** Возможность управлять набором связанных промптов как единым проектом.
