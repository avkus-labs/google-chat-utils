# Журнал изменений (Changelog)

Все заметные изменения в этом проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), и проект придерживается [Семантического Версионирования](https://semver.org/spec/v2.0.0.html).

---

## [3.0.0] - (Текущая версия)

### Added (Добавлено)

- **Полноценная объектно-ориентированная архитектура:** Проект реструктурирован в Python-библиотеку с классами (`GoogleAIStudioJSONParser`, `GeminiAPICodeReconstructor`, `SchemaTransformer`).
- **Пакет `core` с моделями данных:** Введены строго типизированные классы для всех элементов чата, что повышает надежность.
- **CLI с подкомандами:** Реализован единый интерфейс командной строки `utils/cli_v3.py` с подкомандами (`parse`, `reconstruct`, `reconstruct_studio_json`).
- **Реконструкция JSON для Google AI Studio:** Новая команда `reconstruct_studio_json` для создания валидного JSON-файла, который можно импортировать обратно в Studio.
- **Поддержка файлов-оверрайдов:** Добавлена возможность динамически изменять системную инструкцию (`.si`), первое (`.fi`) и последнее (`.li`) сообщения при реконструкции.
- **Утилита для объединения Markdown:** Добавлен отдельный инструмент `tools/markdown_merger.py`.

### Changed (Изменено)

- **Логика парсинга и реконструкции** инкапсулирована в соответствующие классы, а не находится в отдельных скриптах.

---

## [2.0.0] - (Предыдущая версия)

### Added (Добавлено)

- **Поддержка парсинга сырых JSON-экспортов** из Google AI Studio.
- **Концепция "стандартизированного промежуточного JSON"** как единого формата данных после парсинга.
- **Несколько шаблонов для реконструкции** (`vanilla`, `dynamic_si`, `google_vanilla`) для большей гибкости.
- **Инструмент `schema_transformer.py`** для конвертации JSON Schema между форматами OpenAI и Gemini.
- **Информативный вывод в CLI** с пошаговым отчетом о выполнении.

### Changed (Изменено)

- **Ключевое изменение: Отказ от парсинга `.py` файлов.** Проект перешел на работу с более надежным и чистым форматом JSON-экспорта, что значительно повысило стабильность.

---

## [1.0.0] - (Начальная версия)

### Added (Добавлено)

- **Базовый парсер (`parser.py`)** для извлечения данных из `.py` файлов, экспортированных из Google AI Studio.
- **Генерация начальных `.json` и `.md` файлов.**
- **Базовый реконструктор (`reconstructor.py`)** с одним шаблоном для восстановления Python-кода.
