# Добро пожаловать в google-chat-utils v3!

Эта библиотека представляет собой объектно-ориентированную версию утилит для работы с экспортом чатов из Google AI Studio и их преобразования для использования с Gemini API. Версия v3 была полностью переработана с использованием классов для улучшения модульности, читаемости и расширяемости.

## Основные возможности

*   **Парсинг JSON-экспорта**: Загрузка и анализ JSON-файлов, экспортированных из Google AI Studio.
*   **Объектная модель чата**: Представление данных чата (настройки, системные инструкции, история диалога, сообщения, их части, информация об инструментах) в виде структурированных Python-объектов.
*   **Генерация Markdown**: Создание Markdown-представления чата, подходящего для RAG-систем.
*   **Реконструкция Python-кода**: Генерация исполняемого Python-скрипта для Gemini API на основе данных чата и текстовых шаблонов.
*   **Трансформация JSON Schema**: Преобразование JSON Schema между форматами, используемыми OpenAI и Gemini API.

## Ключевые компоненты

Библиотека состоит из нескольких ключевых компонентов:

*   **Модели данных (`core`)**: Определяют структуру данных чата и JSON схем.
    *   `core.chat_elements`: Классы для представления различных элементов чата (настройки, сообщения, части сообщений, ходы диалога и т.д.).
    *   `core.schema_elements`: Классы для представления JSON Schema и деклараций функций.
*   **Парсер (`parsing`)**: Отвечает за чтение и анализ исходных данных.
    *   `GoogleAIStudioJSONParser`: Основной класс для парсинга JSON-файлов из Google AI Studio.
*   **Реконструктор кода (`reconstruction`)**: Генерирует Python-код.
    *   `GeminiAPICodeReconstructor`: Воссоздает Python-скрипт для Gemini API.
*   **Трансформер схем (`transformation`)**: Преобразует JSON Schema.
    *   `SchemaTransformer`: Конвертирует схемы между различными форматами.
*   **Интерфейс командной строки (`cli_v3.py`)**: Предоставляет утилиты для вызова основных функций библиотеки из командной строки (будет реализован).
